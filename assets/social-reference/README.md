# Social card reference

`calculator.png` is the actual calculator screenshot from `docs/screenshots/01-calculator.png` in https://github.com/bernaferrari/calcula, retrieved as a reference for image generation. The share card is an image-generated composition based on that screen, the production logo, and the approved wordmark. It is not a pixel-identical screenshot embed.

The card uses “Calcula” and “Every key does more.” on a purple background. `../social.png` is the 1280 × 640 export; `../social-source.png` is the full-resolution generated composition. `../social-brand-only.png` preserves the previous card without a calculator screen.
